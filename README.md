# SafeClick
الروابط من مصادر مختلفة أمرًا يوميًا، سواء من خلال رسائل واتساب أو البريد الإلكتروني أو مواقع التواصل الاجتماعي. لكن مش كل رابط بنستقبله بيكون آمن، فبعض الروابط ممكن تكون وسيلة للاحتيال الإلكتروني أو سرقة البيانات الشخصية أو توجيه المستخدم إلى مواقع ضارة. ومن هنا جات فكرة SafeClick، وهو مشروع بيهدف إلى مساعدة المستخدمين
